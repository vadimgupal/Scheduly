🤖 Scheduly — помощник для планирования

Я помогу тебе работать с календарём, событиями, задачами, напоминаниями и свободным временем.

📅 Календарь

/createCalendar, /updateCalendar, /deleteCalendar
Создать, изменить, удалить календарь.

/getCalendars
Показать список твоих календарей.

/setDefaultCalendar, /deleteDefaultCalendar, /getDefaultCalendar
Выбрать, удалить, получить календарь по умолчанию.

Если календарь по умолчанию установлен, бот будет использовать его автоматически.


🗓 События

/createEvent, /updateEvent, /deleteEvent
Создать, изменить, удалить событие в календаре.

/getEvents
Показать события из календаря по умолчанию.

При создании события можно указать:
• название;
• описание;
• дату и время начала;
• дату и время окончания;
• timezone;
• место;
• напоминание;
• повтор события.


✅ Задачи

/createTask, /updateTask, /deleteTask
Создать, изменить, удалить задачу.

/getTasks
Показать список задач.

Для задач можно указывать описание, дедлайн и приоритет.


🟢 Свободные слоты

/freeSlots
Показать свободное время в выбранном периоде.

Пример периода:
2026-05-25 2026-05-30

Бот учитывает события из календаря по умолчанию и показывает свободные промежутки.


⏰ Напоминания и сводки

Бот может присылать:
• напоминания о событиях;
• ежедневную сводку;
• недельную сводку.

Для корректной работы нужно указать timezone.


⚙️ Настройки

/setTimezone, /deleteTimezone, /getTimezone
Установить, удалить, получить timezone.

Пример:
Europe/Moscow
Europe/Berlin
Asia/Yerevan

Timezone нужна для правильной работы событий, свободных слотов, напоминаний и сводок.


Во время создания или изменения календаря, события или задачи можно нажать кнопку:
️⏭️ Пропустить, которая пропускает текущий параметр, если он не является обязательным.


Во время создания, изменения или удаления можно нажать кнопку:
❌ Отмена, которая отменит текущую команду.


ℹ️ Подсказка

Сначала лучше выполнить:
1. /setTimezone
2. /setDefaultCalendar

После этого большинство команд будут работать автоматически с календарём по умолчанию.
